# Découvrir EKALIZ

Page de présentation interactive d'**[EKALIZ](https://ekaliz.com/fr/?utm_source=github&utm_medium=readme&utm_campaign=decouverte-ekaliz)**, la plateforme qui transforme la musique en jeu de collection.

👉 **Voir la page :** https://github.com/citicasarl/ekaliz/tree/main/presentation_ekaliz

## Au programme

- **Les collections de cartes musicales** : plus de 2 000 cartes d'artistes, 4 niveaux de rareté (communes, rares, très rares, mythiques), catalogue par décennies, duos et familles musicales, avec une démo d'ouverture de pack qui respecte les vraies proportions de rareté
- **Les badges de culture musicale** : 55 badges répartis en décennies, genres et pays, chacun débloquant un pack de cartes
- **Les données et indicateurs** : biographie, discographie, frise de carrière et indicateurs exclusifs sur chaque artiste

## Technique

Un seul fichier HTML, sans framework : CSS et JavaScript natifs, animations respectant le réglage « réduire les animations » du système. Les couleurs se modifient dans les variables `:root` en tête de fichier.
